# ResearchInsight — Research Paper Analyzer

ResearchInsight is a research paper analysis project developed using Machine Learning and Natural Language Processing (NLP). It helps users analyze academic papers, identify research topics, extract meaningful information, and explore related research.

## Project Overview

The project is organized into three main modules:

### 1. Machine Learning (ML)
- Supervised classification of research papers into topics.
- Uses a trained machine learning model to predict paper categories.
- Supports automated topic identification from research paper text.

### 2. Emotion Spectrum Evaluation (ESE)
- Extracts aspects discussed in research papers.
- Identifies claims made within academic text.
- Detects comparative statements for further analysis.

### 3. Research Search
- Supports searching across research-related topics and domains.
- Uses a research lexicon containing topics and domain classifications.
- Covers technical and non-technical research areas.

## Technologies Used

- Python
- Machine Learning
- Natural Language Processing (NLP)
- Scikit-learn
- Pandas
- Sentence Transformers
- Text processing and feature extraction

## Dataset

The project uses research paper metadata, including available abstracts and associated information, for classification and text analysis.

Dataset completeness may vary depending on the availability of abstracts and metadata.

## Project Objectives

- Simplify the exploration of academic research papers.
- Identify topics and important information from research text.
- Apply machine learning and NLP techniques to research analysis.
- Combine classification, information extraction, and topic-based search in one project.

The repository contains the project's Python source code, supporting modules, saved machine learning models, and associated resources.
